## About   

Personal portfolio website for **Karan P**, Java Full Stack Developer and B.Tech IT student at NPR College of Engineering. Showcases all 10 TAP Academy assignment projects plus personal projects, skills, experience, and a contact form.

## Features

- ✨ **Animated hero section** with rotating role text, floating tech badges, and avatar ring with CSS gradient animation
- 📋 **About section** with stats (CGPA, projects, internships)
- 🛠 **Tech stack section** with skill pills grouped by category
- 🗂 **Projects section** linking all 10 TAP Academy projects + 2 personal projects
- 📅 **Experience timeline** — internships and education history
- 📬 **Contact section** with simulated form submission
- Scroll-reveal animations using Intersection Observer API
- Active navbar link highlighting on scroll
- Mobile-first responsive (hamburger menu on mobile)
